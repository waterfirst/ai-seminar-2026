Step 5. 시계열 교차검증

일반 K-Fold는 미래 데이터 누출. 시계열은 TimeSeriesSplit 필수.

from sklearn.model_selection import TimeSeriesSplit tscv = TimeSeriesSplit(n_splits=5) # Fold 1: [████████░░░░░░░░░░░░] train → [██] test # Fold 2: [████████████░░░░░░░░] train → [██] test # Fold 3: [████████████████░░░░] train → [██] test # Fold 4: [████████████████████] train → [██] test # Fold 5: [████████████████████████] train → [██] test # 항상 과거 → 미래 방향으로만 학습/예측 # 미래 데이터가 절대 훈련에 포함되지 않음

주의: 주가 예측에서 random shuffle은 금기. 2025년 데이터로 학습해서 2026년을 예측해야 의미가 있다.

솔직한 한계

  • R² 음수 — 다중회귀의 수익률 예측은 랜덤보다 못함. 방향만 의미 있음
  • 114일 샘플 — 너무 적음. 최소 2~3년(500일+) 데이터 필요
  • 과적합 위험 — 피처 26개 vs 샘플 114개. 피처 선택(Lasso) 필요
  • 비정상성 — 주가는 비정상 시계열. 수익률로 변환해도 regime change 존재
  • 70% 적중률 — 동전 던지기(50%)보다 낫지만, 실전 수익 보장은 아님
  • 그래도 의미 — "어떤 변수가 영향을 주는가"를 정량적으로 아는 것 자체가 가치

품질 업무에 적용하면?

오늘 한 것 (주가 예측)

  • 입력: 미국 주가, VIX, 환율
  • 타겟: 코스피 등락
  • 모델: RandomForest
  • 검증: TimeSeriesSplit

품질에 적용 (같은 구조)

  • 입력: CVD 온도, 가스비, 챔버 호기
  • 타겟: Vth shift, STIS 등급
  • 모델: RandomForest (동일)
  • 검증: K-Fold (시계열 아님)

프롬프트 예시

"CVD 공정 파라미터(가스비, 온도, 압력)로 Vth shift를 예측하는 랜덤포레스트 모델 만들어줘. CSV 파일은 여기 있어. 어떤 파라미터가 가장 중요한지 피처 중요도로 보여줘."
