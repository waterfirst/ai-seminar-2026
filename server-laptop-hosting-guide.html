삼성디스플레이 품질팀 실전 가이드

서버 노트북에서 HTML/FastAPI 호스팅하는 방법

핸드폰 서버는 실험용으로는 좋지만, 실제 내부 공유와 교육용 페이지 배포는 서버 노트북이 훨씬 안정적이다. 이 문서는 정적 HTML, FastAPI, Ubuntu+Nginx, Windows 기준으로 가장 현실적인 운영 방법을 정리한다.

← 3차 세미나 메인 핸드폰 서버 가이드 왜 노트북인가 가장 쉬운 방법 FastAPI Ubuntu+Nginx Windows
Why

왜 서버 노트북이 더 현실적인가

안정성

  • 전원 연결 고정 가능
  • 발열·배터리 이슈가 핸드폰보다 적음
  • 장시간 서비스 유지가 쉬움

관리성

  • 파일 관리가 편함
  • 로그·백업·권한 분리가 쉬움
  • Nginx/FastAPI/DB까지 확장 가능

공유성

  • 사내망에서 여러 명 접근 가능
  • HTML/리포트/대시보드 운영 가능
  • 팀 서버로 가기 전 입문용으로 좋음
Quick Start

가장 쉬운 방법: 정적 HTML 즉시 공유

Python 내장 서버

cd /path/to/html-files python -m http.server 8080

브라우저 접속: http://노트북IP:8080/파일명.html

언제 이 방법을 쓰나

  • 세미나 자료 공유
  • 내부 HTML 문서 검토
  • 임시 데모
  • 사내망에서 빠른 확인
FastAPI

FastAPI로 서버 노트북에서 호스팅

정적 HTML만이 아니라, 나중에 API·검색·파일다운로드까지 붙일 계획이면 FastAPI가 좋다.

추천 구조

  • FastAPI 앱 하나로 정적 파일 서빙
  • / 기본 페이지 연결
  • 추후 /api 경로 추가 가능

장점

  • HTML 가이드 + API를 한 앱에서 운영 가능
  • 나중에 검색/DB/업로드 기능 붙이기 쉬움
  • Uvicorn + Nginx로 확장 가능
pip install fastapi uvicorn uvicorn fastapi_host:app --host 0.0.0.0 --port 8765

접속 예: http://노트북IP:8765/phone-server-guide.html

Ubuntu

Ubuntu 기준 정식 운영: Nginx

설치

sudo apt update sudo apt install nginx -y sudo systemctl enable nginx sudo systemctl start nginx

배포

sudo cp server-laptop-hosting-guide.html /var/www/html/ sudo cp phone-server-guide.html /var/www/html/ sudo systemctl restart nginx

Nginx가 좋은 이유

  • 80/443 포트 고정 운영
  • 여러 HTML 문서를 한곳에서 관리
  • 나중에 FastAPI 앞단 reverse proxy로 연결 가능
Windows

Windows 노트북에서도 가능

가장 쉬운 방법

cd C:\path\to\html-files python -m http.server 8080

같은 와이파이에서 http://노트북IP:8080 접속

조금 더 본격적으로

  • WSL + Ubuntu + Nginx
  • Windows 방화벽 포트 허용
  • 고정 IP 또는 DHCP 예약 설정

Windows 운영 시 주의

  • 방화벽이 포트를 막을 수 있음
  • 절전모드 진입 시 서비스 중단 가능
  • 공용 운영은 결국 Ubuntu나 VM 쪽이 더 편함
